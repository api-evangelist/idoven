# Idoven

> Idoven builds AI for cardiovascular care. Its Willem platform is a CE-marked Class IIa medical device that analyzes ECGs to detect, diagnose, and monitor cardiac disease — identifying 22 cardiac patterns and 4 intervals across ambulatory devices, diagnostic ECGs, and insertable cardiac monitors. Serves MedTech, Life Sciences (cardiotoxicity monitoring, disease risk scoring), and preventative screening programs. Backed by Insight Partners and Northzone.

This llms.txt was generated by the API Evangelist enrichment pipeline from the Idoven public website and network catalog. Idoven does not publish its own llms.txt. The Willem API host (willem-api.idoven.ai) is EU-geoblocked (returns HTTP 451 to US-origin requests), so its OpenAPI spec is not mirrored here.
